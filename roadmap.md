# Roadmap
## What this is
This is a study task list for language learners, built for one person to use once and keep using. It lets someone sign in, add study tasks tagged by language skill, and see which skill they've been avoiding.

## What Done means
A stranger can go to the live site, create an account with an email and password, add a study task and tag it with a language skill, close the tab, come back later, log back in, and find that task still there with its tag intact. They can also see a simple count of open tasks per skill, so they can tell at a glance which skill they've been neglecting. Nothing beyond that is required.

## Slices
1. Sign up and log in | done-criteria: a person signs up with an email and password and lands on a signed-in page; the person signs out, logs back in with the same credentials, and sees the same signed-in page; the person closes and reopens the tab and is still signed in without re-entering credentials; the person enters a wrong password and sees an error instead of being let in | status: ACTIVE
2. Add tasks and have them stick | done-criteria: a signed-in person adds a task with a skill tag and sees it appear in a list with that tag; the person closes and reopens the tab, logs in, and sees the same tasks still listed with their tags; the person marks a task done and sees it visibly change; two different accounts each see only their own tasks | status: pending
3. See which skill you're avoiding | done-criteria: a person with tasks across at least two skills opens a summary view and sees a count of open tasks per skill; adding a task to a zero-count skill and refreshing shows that count go to 1; completing all tasks under one skill and refreshing shows that count drop to 0 | status: pending

## Backlog
Password reset, Google or other social login, editing or deleting existing tasks, due dates or reminders, streaks or other gamification, multiple lists or folders, sharing tasks with another person, a mobile app, email notifications, rich text on tasks, search, sorting or filtering beyond the skill tag, an admin view, profile pictures, multi-language UI.
