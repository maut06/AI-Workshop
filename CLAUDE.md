# CLAUDE.md

## Stack
Next.js (App Router), TypeScript, plain CSS, Supabase, deployed on Vercel.

## Commands
- `npm run dev` — run the site locally
- `npm run build` — production build; run this and fix any errors before finishing a task

## Never
- Add a dependency without asking first.
- Edit .env or any environment variable.
- Change auth configuration without saying what is changing and why.
- Create new top-level folders.

## Conventions
- All styling stays in plain CSS (app/globals.css and co-located CSS files) — no CSS frameworks or UI libraries.
- roadmap.md, project-state.md, and CLAUDE.md live at the top level of the repo and stay up to date as work happens.
- No real personal data anywhere in the app — fake names and fake content only.
- Explain changes in plain language alongside the code, since every change here is reviewed by a human who directs the work.
